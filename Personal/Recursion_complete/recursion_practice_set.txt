=============================
RECURSION PRACTICE QUESTIONS
=============================

1. Write a recursive function to find the factorial of a number.

2. Write a recursive function to find the nth Fibonacci number.

3. Write a recursive function to find the sum of digits of a number.

4. Write a recursive function to reverse a string.

5. Write a recursive function to check whether a string is a palindrome.

6. Write a recursive function to count the number of digits in a number.

7. Write a recursive function to calculate the power of a number (base^exponent).

8. Write a recursive function to find the largest element in a list.

9. Write a recursive function to convert a decimal number to binary.

10. Write a recursive function to count the number of vowels in a string.
